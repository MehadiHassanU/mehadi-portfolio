description: A machine learning project exploring how different diamond characteristics influence market price and using those patterns to predict diamond values.
problem: Understand how diamond characteristics (carat, cut, color, clarity, depth, table, x, y, z dimensions) influence market price and build a predictive model for diamond valuation.
approach: Used the Kaggle Diamonds dataset (53,940 records). Performed exploratory data analysis to understand feature distributions, correlations, and outliers. Engineered features from categorical variables (cut, color, clarity) using ordinal encoding. Applied log transformation to target variable (price) to handle skewness.
implementation: Trained gradient boosting regressors (XGBoost, LightGBM) with cross-validation and hyperparameter tuning via Optuna. Evaluated using RMSE and MAE on holdout test set. Analyzed feature importance to understand price drivers.
outcome: Trained on 53,940 Kaggle diamond records, gradient boosting reached an RMSE of roughly $200 on the holdout set. Feature importance put carat far ahead of everything else, with cut quality and colour next — physical size dominates price over grading. Log-transforming the skewed price target is what made the residuals behave; the ensemble then picked up the non-linear feature interactions a linear model misses on tabular data.
learning: Feature engineering and target transformation significantly impact model performance on skewed data. Gradient boosting excels at capturing non-linear interactions in tabular datasets. Domain knowledge (e.g., carat^3 relationship with volume) guides effective feature creation.
