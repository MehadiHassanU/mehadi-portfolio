description: A full-stack point-of-sale and customer relationship management system built for a Bangladeshi apparel retailer.
problem: A local Bangladeshi apparel retailer needed a modern, integrated point-of-sale and customer management system that could handle their specific business workflows — including local payment methods (bKash, Nagad, cash), Bengali language support, and VAT-compliant invoicing — while being affordable and maintainable for a small business.
approach: Built a three-person team to deliver a full-stack solution using Next.js 14 with App Router, Supabase for backend (PostgreSQL + Auth + Row Level Security), and Tailwind CSS for styling. Implemented a camera-based barcode scanner using Web APIs, real-time inventory sync, and a loyalty program with tiered rewards. Used jsPDF for PDF invoice generation in Bengali/English with proper BDT formatting.
implementation: The POS interface features live camera scanning with Web Audio feedback, manual SKU lookup, and automatic cart management. Inventory management includes product/category CRUD, low-stock alerts, automatic SKU generation, and barcode label printing via JsBarcode. The CRM tracks customer profiles, lifetime value, purchase history, and shared customer selection. Loyalty system implements Bronze/Silver/Gold tiers with configurable rules. Analytics dashboard uses Recharts for revenue and order visualizations.
outcome: "In production use at a single apparel retailer, where it runs the full transaction loop — counter sales, inventory, customer records and invoicing. Built for the way that business is actually paid: cash, card, bKash and Nagad in BDT, with VAT-compliant invoices generated as PDF in Bengali and English. Delivered by a three-person team with GitHub Actions CI running Vitest and React Testing Library on every merge."
learning: Building for a real business taught me the importance of understanding domain-specific workflows before writing code. Regional payment methods, tax compliance, and language localization are not afterthoughts — they shape the architecture. Working in a small team reinforced the value of clear Git practices, code reviews, and automated testing.
